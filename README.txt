DEV LOKHANDE PORTFOLIO
======================

Files
-----
index.html       Main portfolio page
style.css        Shared visual design and responsive styles
script.js        Mobile navigation, reveal animations and active navigation
projects.html    Project index / case-study starter page

Run locally
-----------
1. Keep all four files in the same folder.
2. Add your portrait as: myphoto.jpeg
3. Add your CV as: Dev_Lokhande_CV.pdf
4. Open index.html in a browser.

Before publishing
-----------------
- Replace or add real project photographs and technical drawings.
- Verify every technical claim and metric. Do not publish a number (for example,
  a drag reduction or continuous current rating) unless you can explain how it
  was measured and provide supporting evidence.
- Add your actual LinkedIn profile URL if you want it displayed.
- Confirm that your CV is current and safe to publish.
- For a public website, deploy the folder using GitHub Pages, Netlify or another
  static hosting provider.

Design notes
------------
The site uses Google Fonts (Manrope and DM Mono) from an external CDN. If the
visitor is offline, fallback fonts will be used. Animations respect the
operating system's reduced-motion preference.
